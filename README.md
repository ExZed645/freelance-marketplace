معرفی کوتاه پروژه (Project Introduction)
این پروژه یک ساختار پایگاه داده رابطه ای نرمال‌شده و قدرتمند را برای یک پلتفرم مدرن بازارچه فریلنسینگ پیاده‌سازی می‌کند. این سیستم مدیریت نقش‌های کاربران (کارفرمایان، فریلنسرها و ادمین‌ها)، انتشار پروژه‌ها در دسته‌بندی‌ها و مهارت‌های مختلف، ارسال پیشنهادها همراه با قوانین سخت‌گیرانه کسب‌وکار، و نمونه‌کارها و گواهینامه‌های حرفه‌ای را بر عهده دارد.


سیستم مدیریت پایگاه داده (DBMS) و نسخهسیستم مدیریت پایگاه داده: PostgreSQL


Design decisions:

مدیریت کاربران و ادمین‌ها: تمام کاربران پلتفرم (کارفرماها، فریلنسرها و ادمین‌ها) در جدول اصلی users قرار دارند. ادمین‌ها با استفاده از یک فیلد بولین is_admin به همراه زمان اعطای دسترسی (admin_granted_at) متمایز می‌شوند تا دسترسی مدیریتی آن‌ها از فعالیت‌های مربوط به پروژه و پیشنهاد جدا بماند.

پروفایل‌ها و اطلاعات حرفه‌ای: یک رابطه ۱:۱ با استفاده از کلید خارجی یکتا و ON DELETE CASCADE جدول users را به user_profiles متصل می‌کند تا عناوین شغلی، بیوگرافی و مکان کاربران ذخیره شود. نمونه‌کارها (portfolios) و گواهینامه‌ها (certificates) در جداول مجزا و نرمال‌شده قرار دارند تا هر کاربر بتواند چندین مورد از آن‌ها را ثبت کند.

روابط چندبه‌چند (دسته‌بندی‌ها و مهارت‌ها): جداول اصلی categories و skills نام‌های یکتا را نگهداری می‌کنند. این جدول‌ها از طریق جداول واسط (project_categories، project_skills و user_skills) به پروژه‌ها و کاربران متصل می‌شوند تا از تکرار داده‌ها جلوگیری شود.

پروژه‌ها و ساختار قیمت‌گذاری: جدول projects از دو نوع قیمت‌گذاری Fixed (ثابت) و Hourly (ساعتی) پشتیبانی می‌کند. قیدهای CHECK تضمین می‌کنند که بودجه و مبالغ پیشنهادی همیشه مثبت (> 0) باشند و وضعیت‌های چرخه عمر پروژه (Draft, Open, In Progress, Completed, Cancelled) پیشرفت کار را ردیابی کنند.

پیشنهادها و یکتایی: قید یکتایی ترکیبی (project_id, freelancer_id) تضمین می‌کند که هر فریلنسر حداکثر یک پیشنهاد برای هر پروژه ثبت کند. وضعیت‌های پیشنهاد (Pending, Accepted, Rejected, Withdrawn) نیز روند ارزیابی را مدیریت می‌کنند.

یکپارچگی داده‌ها و قوانین حذف: کلیدهای خارجی برای وابستگی‌های حیاتی (مانند کارفرماها و فریلنسرها) از ON DELETE RESTRICT استفاده می‌کنند تا از حذف تصادفی اطلاعاتی که سوابق مالی و پروژه‌ها را نابود می‌کنند، جلوگیری شود.
